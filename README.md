<h1>DotFarma API</h1>

<h3>Sistema de Farmácia Hospitalar</h3>
Controle de estoque e dispensação de medicamentos.

<h3>Funcionalidades:</h3>

<ul>
  <li>Cadastro de medicamentos e fornecedores.</li>
  <li>Controle de estoque (entrada/saída).</li>
  <li>Dispensação de medicamentos para pacientes internados.</li>
  <li>Controle de validade e alertas.</li>
  <li>Dashboard com medicamentos próximos ao vencimento.</li>
  <li>API para integração com sistemas de prontuário.</li>
</ul>
